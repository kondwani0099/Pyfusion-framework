<template>
  <div class="card">
    <h2>{{ title }}: {{ count }} (Doubled: {{ doubled }})</h2>
    <input f-model="greeting" />
    <p>{{ greeting }}</p>
    <button @click="increment">+1</button>
    <div f-if="count >= 5">Milestone reached!</div>
  </div>
</template>

<script>
props = {"title": "PyFusion Reactive Counter"}

def data(self):
    return {"count": 0, "greeting": "Hello from PyFusion SFC!"}

def computed(self):
    return {"doubled": lambda s: int(s.get("count", 0)) * 2}

def increment(self):
    self.state.count = int(self.state.count) + 1
</script>

Active OWASP Top 10 Protections

Live report from GET /api/security/audit

View Raw JSON ↗
A01: Access Control & Path Traversal

Blocks ../ traversal, dotfiles (.env), and .py/.db exposure; enforces RPC method allowlists.

A02: Cryptographic Failures

hash_password() uses PBKDF2-HMAC-SHA256 (260k iterations) + random salt & constant-time comparison.

A03: SQLi & XSS Injection

100% parameterized SQL statements in FusionDB + SQL identifier validation + automatic HTML escaping.

A04: Rate Limiting & DoS Protection

Sliding-window IP rate limiter (180 req/min) returning 429 Retry-After + 2MB max request body size cap.

A05: Security Headers

Injects X-Content-Type-Options: nosniff, X-Frame-Options: SAMEORIGIN, Referrer-Policy, and Permissions-Policy.

A07: CSRF Token Verification

HMAC-SHA256 signed CSRF tokens with SameSite=Lax cookie and automatic X-CSRF-Token RPC header.
